# 超级玛丽 H5

一个纯 HTML5 Canvas 实现的超级玛丽风格小游戏，支持：

- PC 键盘操作
- 手机摇杆 + 按钮操作
- 平台跳跃、怪物、金币、掉坑、终点旗帜

## 运行方式

直接打开 `index.html` 即可运行，或使用本地静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 操作说明

- **PC**
  - `←` / `→`：移动
  - `空格` 或 `↑`：跳跃
  - `Z`：冲刺
  - `R`：失败/胜利后重新开始
- **手机**
  - 左侧摇杆：控制移动方向与力度
  - 右侧按钮：跳跃/冲刺
